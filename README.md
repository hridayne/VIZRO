## Installation information
The desktop app is distributed without a trusted Windows publisher certificate or Apple Developer ID/notarization. Operating-system security warnings may appear. Mac ad-hoc signing provides local integrity only.

Native binary auto-updates are disabled for this unsigned release. Download and install future binary releases manually. Online Plugin-controlled pages, settings and opening tune remain available.

Native installation/mount and short launch smoke checks passed. Real account login, office network-drive access, midnight rollover and customer-device performance require acceptance testing.

This repository distributes desktop installers; the product source is maintained separately.
